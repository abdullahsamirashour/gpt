# 📦 ضغط الفيديو والصوت

[فتح النسخة المستقرة في Google Colab](https://colab.research.google.com/github/abdullahsamirashour/gpt/blob/main/telegram-smart-compressor/Smart_Compressor.ipynb)

أداة Colab بسيطة لضغط ملفات الفيديو والصوت في Telegram وإرجاع النتيجة مباشرة إلى قناة خاصة.

## الاستخدام

بعد الإعداد الأول:
1. ابعت الصوت أو الفيديو إلى قناة **📦 ضغط الفيديو والصوت**.
2. افتح نفس Colab واضغط **تشغيل**.
3. النتيجة ترجع للقناة تلقائيًا.

## إعادة معالجة نتيجة

اعمل Reply على النتيجة:
- `1` — نفس الإعداد.
- `2` — ضغط أقوى.
- `3` — صوت فقط.
- `80` — استهداف حوالي 80 MB، ويمكن تغيير الرقم.

الأوامر القديمة تظل مدعومة للتوافق.

## الأداء

- تنزيل متوازي Turbo لأغلب الملفات الكبيرة مع fallback تلقائي.
- `cryptg` لتسريع تشفير Telethon.
- Pipeline لتنزيل الملف التالي أثناء معالجة الحالي.
- Smart Lecture sampling لضبط جودة الفيديو حسب طبيعة المحتوى.
- Progress حي في Colab بدل طباعة عشرات السطور.
